## Plan — 6 Independent Tasks (parallelizable)

### Task 1: quizPanel.ts (880 → 4 modules)
**New files under `src/content/quiz/`:**
- `QuizRenderer.ts` — DOM rendering, question display, option buttons
- `QuizStateMachine.ts` — state transitions (loading → question → answer → review → complete)
- `QuizEventHandler.ts` — keyboard shortcuts, click handlers, message listeners
- `QuizStorage.ts` — session storage, progress persistence, result saving
- `quizPanel.ts` → thin orchestrator (~100 lines) importing above

### Task 2: MapBuilder.tsx (654 → 5 modules)
**New files under `src/components/kpss/map/`:**
- `NodeRenderer.tsx` — node shapes, labels, icons, hover states
- `EdgeRenderer.tsx` — curved edges, arrows, connection lines
- `LayoutEngine.ts` — D3 force layout, position calculation, zoom/pan math
- `MapInteractions.tsx` — drag, click, hover, context menu handlers
- `MapDataTransformer.ts` — curriculum → nodes/edges, filtering, search highlighting
- `MapBuilder.tsx` → composer (~120 lines)

### Task 3: detoxBlocker.ts (597 → 4 modules)
**New files under `src/content/detox/`:**
- `SiteMatcher.ts` — URL pattern matching, wildcard/regex, blocked check
- `BlockerUI.ts` — overlay injection, countdown timer, redirect page
- `BlockerState.ts` — enabled/disabled, end time, site list state machine
- `StorageSync.ts` — chrome.storage listener, settings sync, cross-tab
- `detoxBlocker.ts` → coordinator (~100 lines)

### Task 4: useSidePanelChat.ts (566 → 4 modules)
**New files under `src/sidepanel/chat/` (new folder):**
- `ChatState.ts` — Zustand store: messages, streaming state, session id
- `ChatMessageHandler.ts` — send, retry, edit, delete, regenerate logic
- `ChatStorage.ts` — session persistence, export, import, history
- `ChatAIClient.ts` — API calls, streaming parser, error handling
- `useSidePanelChat.ts` → facade hook (~80 lines)

### Task 5: KpssView.tsx (534 → 5 modules)
**New files under `src/components/kpss/`:**
- `TabNavigator.tsx` — tab bar, routing, active state
- `ExamList.tsx` — past exams table, filters, pagination
- `TopicTree.tsx` — curriculum tree, expand/collapse, search
- `ProgressCharts.tsx` — chart components (reuses kpssChartDrawer)
- `KpssViewState.ts` — Zustand store for view state
- `KpssView.tsx` → shell (~100 lines)

### Task 6: kpssChartDrawer.ts (532 → 4 modules)
**New files under `src/utils/charts/` (new folder):**
- `ChartConfigBuilder.ts` — Chart.js / canvas config objects, themes
- `ChartDataTransformer.ts` — raw data → chart datasets, aggregations
- `CanvasRenderer.ts` — low-level canvas drawing, gradients, animations
- `ChartExporter.ts` — PNG/PDF export, print layout
- `kpssChartDrawer.ts` → deprecated barrel export or thin wrapper
