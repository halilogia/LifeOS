# ZenTodo: Premium New Tab Interface

ZenTodo is a high-end Chrome extension that replaces your New Tab page with a minimalist, focused, and aesthetically pleasing To-Do list environment.

## Features
- **Modern Digital Clock**: Keep track of time with a minimalist elegant clock.
- **Dynamic Date**: Localized date display.
- **Glassmorphic UI**: A premium frosted glass effect for the task container.
- **Local Persistence**: Tasks are saved locally using `chrome.storage.local`.
- **Inspirational Quotes**: Refreshing quotes to keep you motivated.
- **Smooth Animations**: High-quality transitions for task interactions.

## How to Install
1. Open Chrome and go to `chrome://extensions/`.
2. Enable **Developer mode** (top right).
3. Click **Load unpacked**.
4. Select the project folder: `/home/halile/Masaüstü/GitHub/In Progress/chrome-extension-todo`.

## Project Structure
- `manifest.json`: Configuration for the Chrome Extension (MV3).
- `newtab.html`: The core structure.
- `newtab.css`: Premium styling (Inter font, dark mode, glassmorphism).
- `newtab.js`: Logic for CRUD operations and time tracking.
