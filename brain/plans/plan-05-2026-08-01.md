# BIST Satış Fiyatı + Kâr/Zarar + Satış Geçmişi

## Problem

`handleConfirmSell` satış fiyatı parametresini (`_sellPrice`) alıyor ama **kullanmıyor** (alt çizgi öneki = bilerek yoksayılıyor). Satış butonuna basınca:

- `lotCount` düşüyor / hisse siliniyor ✅
- Satış fiyatı **kaydedilmiyor** ❌
- Gerçekleşen kâr/zarar **hesaplanmıyor** ❌
- Satış geçmişi **yok** ❌

Kullanıcı "45 lotu X TL'den sattım" bilgisini giriyor ama o bilgi kayboluyor.

## Amaç

Satış işlemi tam olsun:
1. Satış fiyatı kaydedilsin (alış fiyatıyla karşılaştırılıp kâr/zarar hesaplansın)
2. Satış geçmişi listesi olsun (hangi hisse, kaç lot, hangi fiyattan, ne zaman, kâr/zarar)
3. Portföy toplam değeri doğru kalsın

## Değişiklikler

### [NEW] `src/types/stock.ts` — `StockTradeHistory` tipi
```ts
export interface StockTradeHistory {
  id: string;
  symbol: string;
  displayName: string;
  lotCount: number;      // satılan lot
  sellPrice: number;     // satış fiyatı (TL)
  buyPrice: number;      // satış anındaki alış maliyeti (TL)
  realizedProfit: number; // (sellPrice - buyPrice) * lotCount
  realizedProfitPercent: number; // % kâr/zarar
  soldAt: string;        // ISO tarih
}
```
